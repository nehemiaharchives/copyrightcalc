# copyrightcalc

日本著作権保護期間計算ツール（`index.html`）です。ブラウザだけで動く静的ページとして実装されています。

URL: [https://nehemiaharchives.github.io/copyrightcalc/](https://nehemiaharchives.github.io/copyrightcalc/)

## Features

- 著作物タイプの選択
  - `個人著作物`
  - `団体名義著作物`
  - `映画の著作物`
  - `無名・変名著作物`
- 入力 UI の自動切り替え
  - `個人著作物` 選択時は `著作者死亡年` を入力
  - それ以外は `公表年` を入力
- 外国著作物フラグ対応
  - `外国著作物` を選ぶと `戦時加算日数` 入力欄を表示
- 保護期間の計算ロジック
  - 旧法（50年）と新法（70年）を両方計算
  - 2018年改正の経過措置を反映
    - 2018年時点で旧法上まだ存続中なら70年へ延長
    - 2018年以前に消滅済みなら復活しない
- 結果表示
  - 保護期間満了年（年末）
  - パブリックドメイン化日（翌年1月1日）
  - 外国著作物かつ戦時加算日数がある場合の補足表示
  - 判定ロジックのテキスト表示

## Notes

- 日本法（2026年時点）ベースの簡易ツールです。
- 戦時加算は簡略化実装で、厳密な日単位判定は行いません。
- 共同著作、未公表作品、実名化などの特殊ケースには未対応です。
