# copyrightcalc

日本著作権保護期間計算ツール（`index.html`）です。ブラウザだけで動く静的ページとして実装されています。

URL: [https://nehemiaharchives.github.io/copyrightcalc/](https://nehemiaharchives.github.io/copyrightcalc/)

## 概要

- 著作物タイプの選択
  - `個人著作物`
  - `団体名義著作物`
  - `映画の著作物`
  - `無名・変名著作物`
- 入力 UI の自動切り替え
  - `個人著作物` 選択時は `著作者死亡年` を入力
  - それ以外は `公表年` を入力
- 外国著作物フラグ対応
  - `外国著作物` を選ぶと `戦時加算日数` 入力欄を表示
- 保護期間の計算ロジック
  - 旧法（50年）と新法（70年）を両方計算
  - 映画の旧法分岐に対応
    - 実名の個人名義: `死後38年`
    - その他（団体名義等）: `公表後33年`
  - 2018年改正の経過措置を反映
    - 2018年時点で旧法上まだ存続中なら70年へ延長
    - 2018年以前に消滅済みなら復活しない
- 結果表示
  - 保護期間満了年（年末）
  - パブリックドメイン化日（戦時加算がなければ翌年1月1日）
  - 外国著作物かつ戦時加算日数がある場合の補足表示
  - 判定ロジックのテキスト表示

## 利用方法

### 1. 個人著作物

1. `著作物の種類` で `個人著作物` を選択
2. `著作者死亡年` を入力（例: `1970`）
3. `外国著作物か` は通常 `日本著作物`
4. `保護期間を計算` を押す

旧法 `死後50年` と新法 `死後70年` を比較し、2018年時点で存続していたかどうかで最終満了年を決定します。

### 2. 公表年ベース（団体名義・無名変名）

1. `著作物の種類` で `団体名義著作物` または `無名・変名著作物` を選択
2. `公表年` を入力（例: `1965`）
3. `保護期間を計算` を押す

旧法 `公表後50年` と新法 `公表後70年` を比較します。

### 3. 映画の旧法

1. `著作物の種類` で `映画の著作物` を選択
2. `映画（旧法）判定モード` を選択
   - `実名の個人名義（旧法: 死後38年）`
   - `その他（旧法: 公表後33年）`
3. `公表年` を入力
4. `実名の個人名義` を選んだ場合のみ `映画著作者死亡年` を入力
5. `保護期間を計算` を押す

映画の旧法は一般著作物と計算式が異なる計算をします。

### 4. 複雑なケース（外国著作物 + 戦時加算）

1. 上記 1〜3 のいずれかで必要項目を入力
2. `外国著作物か` を `外国著作物` に変更
3. 根拠資料で確認した `戦時加算日数` を入力（例: `3794`）
4. `保護期間を計算` を押す

戦時加算日数が 0 より大きい場合、PD化日は「翌年1月1日」から日単位で後ろにずれます。

### 5. チャップリンのような例（映画・実名個人名義・戦時加算あり）

例として以下を入力します。

1. `著作物の種類`: `映画の著作物`
2. `映画（旧法）判定モード`: `実名の個人名義（旧法: 死後38年）`
3. `公表年`: `1936`（対象作品の公表年）
4. `映画著作者死亡年`: `1977`（Charles Chaplin）
5. `外国著作物か`: `外国著作物`
6. `戦時加算日数`: `3794`（対象作品に適用できる場合）

この入力例では次の計算になります。

- 旧法満了: `1977 + 38 = 2015年末`
- 2018年改正前に消滅済みのため延長なし
- 基本PD化日: `2016年01月01日`
- 戦時加算 `3794` 日を反映したPD化日: `2026年05月22日`

## 補足

- 日本法（2026年時点）ベースの簡易ツールです。
- 戦時加算は簡略化実装で、厳密な日単位判定は行いません。
- 共同著作、未公表作品、実名化などの特殊ケースには未対応です。
